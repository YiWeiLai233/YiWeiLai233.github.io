数据库备份需要手动执行，没有自动备份配置。备份命令：

# 备份 MySQL

docker exec wms-mysql mysqldump -uroot -pWms@2026 wms > backup\_$(date +%Y%m%d).sql

# 备份上传的图片

docker cp wms-backend:/app/uploads ./uploads\_backup

如果你想备份整个数据卷：

# 备份 uploads 卷

docker run --rm -v wms\_uploads\_data:/data -v $(pwd):/backup alpine tar czf /backup/uploads\_backup.tar.gz -C /data .

# 备份 mysql 卷

docker run --rm -v wms\_mysql\_data:/data -v $(pwd):/backup alpine tar czf /backup/mysql\_backup.tar.gz -C /data .
