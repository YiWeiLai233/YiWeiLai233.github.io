请基于当前 WMS 项目，在「系统管理」中新增库存预警配置模块。



模块名称：



```text

库存预警设置

```



功能目标：



```text

1\. 支持配置 SKU 的低库存预警数量。

2\. 支持配置 SKU 的缺货预警数量。

3\. 支持按仓库维度配置预警阈值。

4\. 支持启用 / 禁用某条预警规则。

5\. 支持库存查询时标记库存状态。

6\. 支持仪表盘或库存页面展示低库存、缺货商品。

7\. 后续可被 AI 智能助手调用，用于回答“哪些商品快缺货了”。

```

\## 2. 功能范围



本模块用于配置库存数量预警规则。



预警类型：



```text

LOW\_STOCK    低库存预警

OUT\_OF\_STOCK 缺货预警

```



库存状态判断规则：



```text

如果可用库存 quantity <= out\_of\_stock\_threshold，则状态为缺货。

如果可用库存 quantity <= low\_stock\_threshold，则状态为低库存。

如果可用库存 quantity > low\_stock\_threshold，则状态为库存正常。

```



注意：



```text

缺货阈值应小于或等于低库存阈值。

例如：

缺货阈值 = 0

低库存阈值 = 10



库存为 0：缺货

库存为 1 到 10：低库存

库存大于 10：正常

```

\## 3. 数据库设计



新增 SQL 文件：



```text

wms-backend/sql/V20260615\_\_stock\_alert\_config.sql

```



新增表：



```sql

CREATE TABLE IF NOT EXISTS stock\_alert\_config (

&#x20;   id BIGINT PRIMARY KEY AUTO\_INCREMENT COMMENT '库存预警配置ID',

&#x20;   sku\_id BIGINT NOT NULL COMMENT 'SKU ID',

&#x20;   warehouse\_id BIGINT DEFAULT NULL COMMENT '仓库ID，NULL表示所有仓库通用',

&#x20;   low\_stock\_threshold INT NOT NULL DEFAULT 10 COMMENT '低库存阈值',

&#x20;   out\_of\_stock\_threshold INT NOT NULL DEFAULT 0 COMMENT '缺货阈值',

&#x20;   enabled TINYINT NOT NULL DEFAULT 1 COMMENT '是否启用：1-启用 0-禁用',

&#x20;   remark VARCHAR(500) DEFAULT NULL COMMENT '备注',

&#x20;   created\_by BIGINT DEFAULT NULL COMMENT '创建人ID',

&#x20;   created\_by\_name VARCHAR(50) DEFAULT NULL COMMENT '创建人名称',

&#x20;   updated\_by BIGINT DEFAULT NULL COMMENT '更新人ID',

&#x20;   updated\_by\_name VARCHAR(50) DEFAULT NULL COMMENT '更新人名称',

&#x20;   deleted TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删 1-已删',

&#x20;   created\_at DATETIME NOT NULL DEFAULT CURRENT\_TIMESTAMP COMMENT '创建时间',

&#x20;   updated\_at DATETIME NOT NULL DEFAULT CURRENT\_TIMESTAMP ON UPDATE CURRENT\_TIMESTAMP COMMENT '更新时间',

&#x20;   UNIQUE KEY uk\_sku\_warehouse\_deleted (sku\_id, warehouse\_id, deleted),

&#x20;   KEY idx\_sku\_id (sku\_id),

&#x20;   KEY idx\_warehouse\_id (warehouse\_id),

&#x20;   KEY idx\_enabled (enabled)

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='库存预警配置表';

```



说明：



```text

warehouse\_id 为 NULL 表示该 SKU 所有仓库共用该预警规则。

如果同一个 SKU 在某个仓库配置了专属规则，则优先使用仓库专属规则。

如果没有专属规则，则使用通用规则。

```



\---



\## 4. 预警规则优先级



库存状态计算时，规则优先级如下：



```text

1\. 优先查找 sku\_id + warehouse\_id 的专属配置。

2\. 如果没有专属配置，则查找 sku\_id + warehouse\_id IS NULL 的通用配置。

3\. 如果仍然没有配置，则使用系统默认阈值。

```



默认阈值：



```text

low\_stock\_threshold = 10

out\_of\_stock\_threshold = 0

```

\## 8. 后端 Service 规则



`StockAlertConfigService` 需要提供：



```text

create

update

delete

enable

findByPage

getLowStockList

getOutOfStockList

getStatistics

calculateStockStatus

```



核心方法：



```java

String calculateStockStatus(Long skuId, Long warehouseId, Integer quantity);

```



计算逻辑：



```text

1\. 查询 skuId + warehouseId 的启用配置。

2\. 如果没有，查询 skuId + warehouse\_id IS NULL 的启用配置。

3\. 如果仍然没有，使用默认阈值。

4\. 如果 quantity <= outOfStockThreshold，返回 OUT\_OF\_STOCK。

5\. 如果 quantity <= lowStockThreshold，返回 LOW\_STOCK。

6\. 否则返回 NORMAL。

```
