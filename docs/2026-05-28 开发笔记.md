# 2026-05-28 开发笔记

## 深夜模式适配

### 新增文件
- `fount/src/composables/useTheme.ts` — 主题 composable

### 核心逻辑
- 首次访问：跟随系统 `prefers-color-scheme`，自动检测深浅色
- 手动切换：light ↔ dark 两态切换，去掉"跟随系统"中间态
- 持久化：用户选择存 localStorage，刷新保持
- 实现方式：`<html>` 元素切换 `.dark` class，`:root.dark` 覆盖 CSS 变量

### 切换按钮
- 位置：HomeView 导航栏，品牌名和登录按钮之间
- 样式：44px 圆形，紫色光环 `box-shadow`，深色模式独立配色
- 图标：浅色模式 🌙，深色模式 ☀️

### 踩坑记录
- AdminView 的深色覆盖选择器名与实际类名大量不匹配（如 `.td-name` 实际是 `.name-cell`，`.badge.gray` 实际是 `.badge-gray`）
