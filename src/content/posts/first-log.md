未来观测站用于整理个人开发项目、技术日志、二次元收藏和日常记录。它不是单纯作品集，也不是纯技术博客，而是一个长期维护的个人内容档案。

当前站点采用静态内容工作流：文章使用 Markdown 管理，项目档案使用内容集合维护，页面通过构建流程统一生成。

## 站点定位

这个站点的核心身份是“忆丶未来的个人观测站”。它需要同时容纳几类内容：开发项目、技术复盘、日常兴趣、二次元收藏和站点自身迭代。页面风格可以二次元，但内容不能空。

## 第一版内容结构

第一版先分成四个区域：

- 首页：负责建立视觉氛围和展示最近内容。
- 项目档案：整理真实项目，不再只放临时卡片。
- 开发日志：记录每次项目推进中的技术判断和问题处理。
- 观测收藏：保留番剧、游戏、音乐和碎片灵感。

## 维护方式

不做登录后台，意味着维护方式要足够清楚。项目和文章都放在 `src/content`，用 Markdown 更新；固定页面文案放在 `src/pages`；站点名称、导航和基础信息放在 `src/data`。

## 后续目标

下一步重点是补真实内容：根据已有项目文档和 GitHub 仓库，把 DreamArchive、WMS、PaperBackup 和本站本身的档案写完整，再逐步补截图、标签、归档和搜索。
