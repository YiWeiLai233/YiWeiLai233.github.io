静态站适合以内容展示为核心的个人博客。Astro 可以将页面构建成静态文件，保持访问速度、部署成本和维护复杂度之间的平衡。

未来观测站的内容由 Markdown 和内容集合管理，文章、项目和收藏记录都能以清晰的文件结构沉淀下来。

## 为什么先做静态

个人博客第一阶段最重要的是把内容写出来，而不是维护登录、后台、数据库、接口和权限。静态站省掉了这些复杂度，也降低了部署成本。只要 Markdown 文件写好，构建后就能生成可以发布的静态页面。

## Astro 的位置

Astro 很适合这种内容型站点：页面大部分是静态 HTML，只有少量需要交互的地方才加载前端组件。未来观测站里的任务小组件、看板娘提示这类交互可以用 island 处理，不需要让整个站点都变成单页应用。

## 内容集合

Astro 内容集合可以给 Markdown 加 schema。项目档案需要标题、简介、状态、技术栈和仓库链接；开发日志需要标题、日期、摘要、标签和分类。这样内容不是散落的纯文本，而是有结构的资料库。

## 复盘

这套技术选型的目标很明确：让维护动作尽量接近“写文件”。后续如果需要搜索、标签筛选、RSS 或评论，再按实际需求加，不在第一版提前增加后台复杂度。
