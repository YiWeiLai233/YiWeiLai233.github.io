备案还在走流程，趁着这段把上线需要的服务器侧配置提前做完。

## HTTPS

证书用 Let's Encrypt，签发本身几条命令就完事。真正需要设计的是**续期**——90 天有效期，靠人工记迟早会漏，漏了的那天早上站点会全红。

做法是配定时任务跑续期脚本，脚本里带 `--deploy-hook` 在续期成功后自动 reload nginx。这样"续期"这件事从流程里消失了，不需要任何人记得。

顺手配了 HTTP 到 HTTPS 的 301。除了加密本身，这一步还有个实际好处：避免同一内容存在 http 和 https 两套 URL，那会让搜索引擎的权重分散到两个地址上。

## nginx 配置

静态文件托管，开了 gzip，配了缓存头。配置文件里加了几条：

```
location ~* \.(css|js|png|jpg|svg|woff2)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}
```

有个取舍要注意：CSS 和 JS 用了长缓存，那以后改样式就要靠文件名变化来破缓存。现在没有构建步骤，文件名不会自动带 hash，所以后面改样式时得手动给文件名加个版本号，或者临时把缓存调短。

这条现在先记着，还没遇到，但迟早会踩。

## 404 页

做了一个 `404.html`，还没接进 nginx 的 fallback。这条今天没做，先记下来——不加 `try_files` 的话，任意不存在的路径都会返回首页内容和 200 状态码，对搜索引擎很不友好。

## 量了一下首屏

今天第一次认真统计首屏资源，结果不太好看：

首页引用了八张图，合计约 **1.5 MB**。其中最大的两张是产品概念图，一张 558 KB，一张 477 KB。CSS 部分 `bootstrap.min.css` 232 KB、`custom.css` 110 KB，JS 里 jQuery 87 KB。

静态站没有服务端渲染开销，首屏时间几乎就等于图片下载时间——所以图片是唯一值得动的地方。后面要转 WebP，目标把首屏图片压到 400 KB 以内。

## 顺带发现

`custom.css` 已经 6400 行了，媒体查询 11 处。还没到必须拆分的程度，但在文件里给每个区块加了分段注释，不然改到一半找不到位置。压缩后用 gzip 是 110 KB 原始大小里的一部分，暂时可以接受。
